# Weekend Projects

A collection of small, standalone projects built to learn by doing.

## Projects

- [`snake/`](snake/) — a terminal Snake game in Go.
- [`chip8-emulator/`](chip8-emulator/) — a guided CHIP-8 emulator project. The first milestone is understanding the virtual machine before writing an implementation.

Each project owns its own README, source code, documentation, dependencies, and build instructions.
